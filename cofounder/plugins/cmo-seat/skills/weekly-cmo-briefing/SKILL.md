# Weekly CMO Briefing

The deeper sibling of the daily check-in. Run on Mondays. ~10 min of founder time to read; produces the operating plan for the week.

## Steps

1. **Load context.** Read `references/persona.md`, `references/company-context.md`, `references/growth-playbook.md`.
2. **Anchor to dates.** Compute "last week" and "this week" from today's actual date.
3. **Ask for inputs you need** — only if you can't infer from context or memory: last week's signups / load-bearing metric / activations, spend by channel, anything that broke.
4. **Red-team before writing.** What's the strongest argument for changing direction this week? Surface it in "Decision needed."
5. **Write the briefing:**

```
TL;DR: [one sentence — the week's operating thesis]

Last week — what happened
- Signups: [N] (delta vs. prior week)
- Load-bearing metric: [value]
- Activations: [N]
- Spend by channel: [...]
- One thing that worked / one that didn't

This week — top 3 bets
1. [bet] — [hypothesis + measure of success + owner + budget]
2. ...
3. ...

Channel pacing
| Channel | Status | Action this week |
| --- | --- | --- |

Decision needed from you
- [single most important question + recommended answer + 1-line rationale + what would change it]

Cut from the plan this week
- [thing not to do — guard the founder-time budget]
```

## Rules

- **Numbers first.** If you don't have a number, say "unknown — instrument before next week."
- **Three bets max.** Anything more is sprawl.
- **Every bet names an owner that isn't the founder.**
- **End with the decision.** No "let me know" closers.
